
# Nonstop Nonsense

**Useful things. Useless things. Everything in between.**

Welcome to Nonstop Nonsense! A collection of small, fun, and occasionally useful browser-based tools and games built with HTML, CSS, and JavaScript.

The goal is simple: create entertaining little projects that are easy to access, and easy to use.

## 🌐 Live Website

[Visit Nonstop Nonsense](https://seek307.github.io/nonstop-nonsense/)

## 🛠️ Current Projects

### Wheel Spinner
A customizable spinning wheel for making random selections. Add your own options, give it a spin, and let fate decide!

### Flappy Cole
A little browser game starring Cole, featuring classic Flappy Bird-inspired gameplay, sound effects, background music, and a personal high-score tracker.

## 💻 Built With

- HTML5
- CSS3
- JavaScript
- HTML Canvas API
- Browser Local Storage

No frameworks or external dependencies required.

## 🚀 Running Locally

1. Download or clone this repository.
2. Open `index.html` in your browser.
3. Enjoy!
